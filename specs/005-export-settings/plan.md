# Implementation Plan: Phase 5 — Export & Settings

**Branch**: `005-export-settings` | **Date**: 2026-04-05 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/005-export-settings/spec.md`

## Summary

Add an **Export tab** (CSV, text, PDF with signatures) and a **Settings tab** (PIN change + theme toggle) to `dashboard.html`. All export logic is client-side — no new server calls beyond fetching attendance records. Theme preference is stored in `localStorage`. PIN change requires one new Supabase RLS migration. No new HTML files.

## Technical Context

**Language/Version**: Vanilla JavaScript (ES2020+, async/await), no build step  
**Primary Dependencies**: Supabase JS client v2 (CDN), `config.js` (credentials), Google Fonts (Tajawal). No new libraries — PDF export uses `window.print()` with a dynamically generated print window.  
**Storage**: Supabase — `settings` table (UPDATE pin_hash); `attendance` table (SELECT with signature_data for PDF); localStorage (theme preference)  
**New Migration**: `004_settings_dashboard_rls.sql` — anon UPDATE on settings  
**Testing**: Manual browser testing; no automated test framework  
**Target Platform**: Modern web browser (desktop + mobile); existing `dashboard.html`  
**Project Type**: Extends existing single-file `dashboard.html` — adds two new tab sections  
**Performance Goals**: Export files generate in under 10s for ≤200 records  
**Constraints**: No build system; no new external CDN libraries; all changes in `dashboard.html` + one new migration SQL file; RTL Arabic UI; theme must not flash on load
